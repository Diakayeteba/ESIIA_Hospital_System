# ESIIA Hospital System 🏥

**ESIIA Hospital System** est une application web créée en équipe par les étudiants de l'ESIIA.  
Elle a pour but de **numériser et sécuriser les données personnelles des patients**.

## Fonctionnalités

- 📊 **Tableau de bord** — Vue d'ensemble avec statistiques en temps réel (patients, rendez-vous, médecins, lits)
- 👥 **Gestion des patients** — Ajout, modification et consultation des dossiers patients avec recherche instantanée
- 📅 **Rendez-vous** — Planification et suivi des rendez-vous médicaux
- 👨‍⚕️ **Médecins** — Annuaire des médecins avec spécialités et disponibilité
- 📋 **Rapports** — Statistiques d'admissions mensuelles et répartition par spécialité

## Démarrage rapide

Aucune installation requise. Il suffit d'ouvrir `index.html` dans un navigateur web moderne.

```bash
# Cloner le dépôt
git clone https://github.com/Diakayeteba/ESIIA_Hospital_System.git

# Ouvrir dans le navigateur
open index.html
```
